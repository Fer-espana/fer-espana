## Sobre mí

- **En producción:** diseño, migro y mantengo plataformas web (Angular SSR), apps Flutter en Google Play, APIs Node.js en AWS EC2 e integraciones con Odoo ERP.
- **Datos:** vistas en PostgreSQL y SQL Server, dashboards en Power BI (DAX) y reportería paginada con Report Builder.
- **Formación:** Ingeniería en Ciencias y Sistemas. Sistemas de archivos en C++, compiladores, estructuras de datos avanzadas y hardware embebido.
